# Security policy

This repository discusses personal and organizational exposure.

Do not publish sensitive personal or operational information in issues, pull requests or examples.

Never include:

- real home addresses, routes or routines;
- credentials, secrets or access tokens;
- a real person's identity linked to a vulnerability;
- information obtained from compromised accounts or non-public sources;
- details that could put someone at risk.

Use fictional or anonymized examples whenever possible.

If you need to report something sensitive about this repository, contact the repository owner privately.
