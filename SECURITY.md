# Security policy

This repository discusses personal exposure. Do not publish sensitive personal or operational information in an issue, pull request or example.

Never include:

- a real home address, route or routine;
- a real person's identity linked to a vulnerability;
- credentials, secrets or access tokens;
- information collected from a compromised account or closed source;
- details that could put someone at risk.

Use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise, contact the repository owner through a private channel listed on their GitHub profile.

If someone may be in immediate danger, contact local emergency services. In France, call **17** or **112**.
