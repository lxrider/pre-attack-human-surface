# Politique de sécurité / Security policy

## Français

Ce dépôt étudie l'exposition informationnelle humaine et organisationnelle **dans un cadre défensif**.

**Ne publiez pas**, dans les issues, pull requests ou exemples : adresses privées, déplacements ou routines de personnes réelles ; identifiants, secrets, jetons ; liens nominaux entre individus et vulnérabilités ; données extraites de comptes compromis ; éléments opérationnels susceptibles d'exposer une organisation ou une personne.

Utilisez des données **fictives ou rigoureusement assainies**. Ne testez pas de personnes, de services tiers ou de systèmes sans autorisation explicite. Pour signaler un problème de sécurité lié au dépôt, contactez le mainteneur **par un canal privé déjà disponible** ; ne placez pas de détails sensibles dans une issue publique.

## English

This repository discusses personal and organizational information exposure for **defensive analysis**.

Do **not** post real home addresses, travel patterns, routines, credentials, secrets, access tokens, identities linked to vulnerabilities, compromised data, or sensitive operational details in issues, pull requests, or examples.

Use **fictional or carefully sanitized** cases. Do not test people, third-party services, or systems without explicit authorization. Report sensitive repository issues **privately through an existing owner contact channel**, not in a public issue.
